# Coffee Point — меню в стиле кофейного автомата

Сенсорное меню для кофейни: категории слева, плитки напитков, выбор объёма, молока и сахара, корзина и экран «Заказ готовится».
Один файл `index.html`, без сборки и зависимостей. Работает на телефоне, планшете и киоске.

## Запуск на GitHub Pages
1. Создайте новый репозиторий на github.com (например, `coffee-menu`).
2. Нажмите **Add file → Upload files** и загрузите `index.html` и `README.md`.
3. Откройте **Settings → Pages**. В разделе **Build and deployment** выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`, затем **Save**.
4. Через 1–2 минуты сайт откроется по адресу `https://ВАШ_ЛОГИН.github.io/coffee-menu/`.

## Локально
Откройте `index.html` в браузере двойным щелчком.

## Как изменить меню
В начале блока `<script>` в `index.html`:
- `CONFIG.currency` — валюта;
- `CATS` — категории;
- `MENU` — позиции (название, иконка, цена, описание);
- `SIZES`, `MILKS` — объёмы и виды молока с доплатой.

Для киоска откройте сайт в браузере на весь экран (F11).
